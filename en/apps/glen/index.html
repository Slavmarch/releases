Glen

Glen

Bring your scattered files together

See the features

See the files piling up in Downloads and on your desktop in one place. Your files stay where they are; Glen only organises the list.

Download · coming soonWindows 10·11 · in testingmacOS · coming soon

Features

Newly arrived files

Get told the moment a new file appears, and see where it came from.

Files stay put

Glen never moves or deletes files behind your back. It moves only when you click, and deletes only to the Recycle Bin.

Stars and labels

Star important files and label them by task to find them later.

Find files

Search by name, label or where a file came from. You can search from the island too.

Find thrown-away files

See where a file in the Recycle Bin used to be.

One home folder

Files made by Optic and Parser gather in the Glen folder.

Privacy

When Glen scans, it never opens file contents; it looks only at names, sizes and dates. It does not move or delete files. See the Privacy Policy for details.
