Privacy Policy

Effective date: [2026-__-__]

Lagoonworks ("the Operator") makes and distributes OVERMIND, Ovi Family, Parser, Optic and Glen (together, "the Apps"). This policy explains how the Apps handle personal information.

1. Summary

  • The Operator does not offer sign-up or accounts and does not use ad tracking or usage analytics. The Operator does not run any server that receives and stores information from the Apps. The one exception is when the user presses [Send] in [Report a bug]; what is sent is not stored and is forwarded to the Operator's support mailbox (section 2).
  • App installers and updates are downloaded from GitHub. GitHub gives the Operator only totals, such as download counts, and does not tell the Operator who downloaded a file.
  • Information the Apps handle is stored on the user's own computer.
  • Only for features the user turns on (AI, weather, calendar and the like) do the Apps send information directly from the user's computer to the company providing that service. The Operator neither sees nor receives it.

2. Personal information the Operator collects

The Operator does not collect personal information through the Apps.

Exception: if the user chooses to send the Operator a file made with Ovi Family's [Collect logs] or an e-mail asking for help, the Operator uses what it contains (app versions, operating system, error logs, the sender's e-mail address) only to answer that request, and destroys it without delay once the request is closed. The file is made on the user's computer and sent by the user; logs that hold text the user wrote (such as Parser's text-recognition log) are left out, and the user can open the file before sending it.

Reports sent with [Report a bug] (added 2026-10-31, for the next effective version): the information below is sent only when the user presses [Send] in Ovi Family's [Report a bug]. Nothing is sent before that, and the user can see the list of logs and open the file before sending.

6. Deleting information

There is nothing to delete on any server of the Operator. Information on the user's computer can be deleted by:

  • One item at a time: deleting the item (an event, a recording, a conversation and so on) in each App.
  • Everything an App has stored: pressing [Delete all records] in that App deletes its folder listed in section 3 and closes the App (in OVERMIND, Parser and Optic under 'About' in settings; in Glen at the lower left of its window). This is the way to do it on a Mac.
  • When uninstalling (Windows): Parser and Optic ask during uninstallation whether to delete the records as well; OVERMIND, Glen and Ovi Family delete the App's folder if "Delete the application data" is ticked in the uninstall window; when uninstalling from Ovi Family, they delete it if "Also delete my records" is ticked. If the user does not choose this, the folder remains.
  • AI keys: these are not deleted by the methods above, because several Apps share them. Delete them with [Delete] under 'AI connections' in OVERMIND settings, or delete the 'OVERMIND' entries in the operating system's secure store.
  • Files the user saved (PDFs, captures, files in the Glen folder and so on) are not deleted by the methods above.

7. Children under 14

The Apps have no accounts and the Operator does not receive personal information, so the Apps do not check age. [This section will change if paid plans or accounts are added.]

8. Security measures

  • AI keys are kept only in the operating system's secure store; only the last four characters are shown on screen, and Optic and Parser mask keys in error logs.
  • OVERMIND installs an update only if the Operator's signature on it is valid. Ovi Family checks a list signed by the Operator and installs a downloaded installer only if its SHA-256 fingerprint matches that list.
  • On Windows, the channel between the Apps is restricted so that only the user account that created it can open it; on Mac, the hub accepts connections only from the same user account (not yet tested on a Mac).
