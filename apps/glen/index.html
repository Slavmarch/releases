Glen

흩어진 파일을 한곳에

할 수 있는 것 보기

다운로드·바탕화면에 쌓이는 파일을 한곳에서 보여 줘요. 파일은 제자리에 두고, 목록만 정리해요.

내려받기 · 준비 중Windows 10·11 · 시험 중macOS · 준비 중

할 수 있는 것

새로 온 파일

새 파일이 생기면 바로 알려 주고, 어디서 받았는지도 보여 줘요.

파일은 제자리

Glen 은 파일을 몰래 옮기거나 지우지 않아요. 옮기기는 누를 때만, 지우기는 휴지통으로만 해요.

별과 이름표

중요한 파일에 별을 달고, 일 이름으로 이름표를 붙여 찾아요.

파일 찾기

이름·이름표·받은 곳으로 찾아요. 섬에서도 찾을 수 있어요.

버린 파일 찾기

휴지통에 버린 파일이 어디 있었는지 알려 줘요.

한 곳 폴더

Optic·Parser 가 만든 파일이 Glen 폴더에 모여요.

안심하고 쓰도록

파일을 훑을 때 내용은 열지 않고 이름·크기·날짜만 봐요. 파일은 옮기거나 지우지 않아요. 자세한 것은 개인정보 처리방침에 있어요.

바뀐 것

1.2.02026-10-31최신

이용약관 동의와 내 기록 지우기가 생겼어요

  • 설치할 때 이용약관 동의 화면
  • 창 왼쪽 아래에 이용약관·개인정보 처리방침·쓰는 부품 이용권
  • [모든 기록 지우기], 앱을 지울 때 '데이터 삭제'를 고르면 기록도 지워요
  • 흐린 글자를 더 또렷하게

노치에서 파일을 찾고, 트레이 'Glen 열기' 하얀 창을 고쳤어요

  • 노치에서 파일 찾기
  • 노치 최근 파일: 설치 파일도 [열기]
  • .bat 같은 실행 파일은 새 파일 알림에 [열기] 없음
  • 트레이 'Glen 열기' 하얀 창 고침
  • 트레이 '기록 보기' 뺌 (Ovi Family [기록 모으기]로)
